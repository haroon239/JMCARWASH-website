# JM Car Wash & Cleaning

A responsive car wash and detailing website built with Next.js, React, TypeScript, and Tailwind CSS.

## Features

- Responsive landing page and mobile navigation
- Service detail pages with WhatsApp booking
- Location-specific service pages
- Animated testimonials, statistics, and content sections
- Before-and-after vehicle comparison
- FAQ accordion and contact actions
- Optimized images, metadata, favicons, and web manifest
- Static generation for service and location routes

## Local development

Install dependencies and start the development server:

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

## Production

Create and run a production build:

```bash
npm run build
npm start
```
